# P1 静态模型依据
采用放松的 A 姿检查轮廓，建模正面为 −Y。主体、四肢、发束及衣物按部件建模；金属件保持独立。用立绘的眼线、帽檐斜率、双排扣间距和腰腿比例优先校对正面。

|部件|来源与建模取舍|
|---|---|
|Face / Eyes|透明立绘与 clip_05.40s.png 的窄杏眼、上扬外眼角、酒红瞳、尖下巴。|
|Hair / Bows|立绘的长鬓发、交叉额发、双侧红结；长束外层偏冷灰，向内翻出红色。|
|Cap|立绘的斜檐与扇形金属栅条，海报确认帽饰整体轮廓。|
|Jacket / Shoulder / Medals|立绘中白衣中央较亮，黑色侧腰、金扣、单肩穗饰和胸前绶带打破对称。|
|Shorts / Stockings|clip_08.65s.png 与 clip_08.85s.png 的黑色短裤、侧带、腿部浅灰网纹，保留裤脚到靴口的间距。|
|Boots|clip_08.45s.png 和 08.65 秒画面中的靴筒、金扣与红色箭形纹。|
|Cape|clip_07.10s.png、clip_07.50s.png、clip_07.80s.png 的深外面、红内面、侧后下垂长片。A 姿采用静止褶线。|
|Weapon|以立绘中的细索、装饰握柄和尖端为依据，独立集合与手部挂点。未见完整连接机构。|
|未知结构|鞋尖、跟底、披风后幅、长发背侧、披风连接与武器连接是工作假设，相关对象以 UNVERIFIED_ 命名。|
