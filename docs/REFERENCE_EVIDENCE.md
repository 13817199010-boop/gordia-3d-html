## 建模优先级
1. 脸与红色眼睛比例（脸部线条建议卡通着色）
2. 多层黑灰发片、局部红色内衬与蝴蝶结
3. 礼帽与金色镶饰
4. 白色军礼服、双排纽扣和黑色肩饰
5. 黑色短裤、灰色腿部织物层、带装饰的高筒靴
6. 独立的红黑披风、细长武器、金属勋章和挂件

## 质量限制
不能把透明立绘直接贴到一张平面网格冒充3D。背面/鞋底采用单独命名占位对象并作明确标记。所有可见关键元素在默认镜头中需能辨认。
